# Network IDS Project Report

## Objective
The objective of this project is to build a simple Network Intrusion Detection System using Suricata on Kali Linux.

## Methodology
1. Installed Suricata and Wireshark
2. Configured custom Suricata rules
3. Generated network traffic using ping, curl, and nmap
4. Captured packets using Wireshark
5. Observed and analyzed alerts

## Detection Rules Implemented
- ICMP Ping Detection
- HTTP Traffic Detection
- SSH Connection Detection
- TCP SYN Scan Detection
- DNS Traffic Detection

## Tools Used
- Suricata
- Wireshark
- Nmap
- Kali Linux

## Results
The IDS successfully detected suspicious network activities and generated alerts in real time.

## Conclusion
This project demonstrates the implementation of a basic Network Intrusion Detection System capable of monitoring and detecting network traffic anomalies.
